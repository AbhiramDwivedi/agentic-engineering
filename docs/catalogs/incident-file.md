# The Incident File

> **The decision it resolves:** which public agent failure looks like the one you are about to ship?

> **Stub: planned for a later release.**

Public agent failures, cited: the production data-destruction incidents, the approval-gate
bypasses, the injection exfiltrations, the personal-agent exposures, the scale claims that did
not survive review. Each entry is mapped to the pattern or guardrail that would have caught it,
so the file doubles as the evidence behind the maturity verdicts and as the fastest argument for a
control that a team is about to skip. The field has no postmortem culture for agent incidents
yet; a curated, sourced file of them is the closest thing.
